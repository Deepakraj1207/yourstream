# Fonts and lettering

- `src/main/res/font/bangers.ttf`: **Bangers** by The Bangers Project Authors, SIL Open Font
  License 1.1 (`OFL-Bangers.txt`). Comic lettering for headings in the manga style.
- The "ys" logo (`src/main/res/drawable/ys_logo.xml`, the launcher icon) uses glyph outlines of
  **JetBrains Mono Bold** by JetBrains, SIL Open Font License 1.1.
