# Fonts and lettering

- `src/main/res/font/bangers.ttf`: **Bangers** by The Bangers Project Authors, SIL Open Font
  License 1.1 (`OFL-Bangers.txt`). Comic lettering for headings in the manga style.
- The logo (`src/main/res/drawable/ys_logo.xml`) and the launcher icon use glyph outlines of
  **Bangers** ("YS" in a speech bubble), SIL Open Font License 1.1.
